Coverage Area Selection

How should users define the imagery download area in the admin panel?

A

Embedded Minimap with Draw Rectangle

A small MapLibre map (~250px tall) embedded in the Pipelines tab. User draws a rectangle directly on the map. The bbox text field auto-populates from the drawn rectangle and vice versa.

Pros

  • Visual, intuitive — see exactly what you're downloading
  • Two-way sync: draw updates text, text updates rectangle
  • MapLibre is already vendored in the frontend
  • Can show existing imagery coverage as context

Cons

  • Config panel is on port 8097 (localhost only) — needs access to tile server for the basemap
  • More code (~100 lines for draw interaction)
  • Map resources loaded even when not needed
B

Preset Regions + Custom Bbox

A dropdown of named regions (Western US, Arizona, Maricopa County, etc.) that auto-fill the bbox, plus a manual text field for custom coordinates. No map needed.

Coverage area
west, south, east, north (decimal degrees)

Pros

  • Zero additional dependencies
  • Works perfectly on mobile
  • Named regions are self-documenting
  • Easy to add new presets

Cons

  • Custom areas still require knowing coordinates
  • No visual feedback on what you're selecting
  • Preset list needs curation and maintenance
C

Both: Presets + Minimap

Combine A and B. Preset dropdown fills the bbox and centers the minimap. Or draw directly on the map. Best of both worlds.

Pros

  • Quick selection for common areas
  • Visual confirmation for any selection
  • Handles both casual and power users

Cons

  • Most complex implementation
  • Presets + map + text field is a lot of UI for one input
